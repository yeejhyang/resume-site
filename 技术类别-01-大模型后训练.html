一、训练范式

SFT / RLHF / DPO / GRPO 的区别？
  • SFT：监督微调，在 (prompt, 答案) 上做交叉熵，学会模仿，是后训练第一步。
  • RLHF：训 Reward Model 打分 + PPO 优化，能主动优化目标，但需训 critic、流程复杂、易 reward hacking。
  • DPO：跳过 RM 和 RL，用闭式 loss 直接从偏好数据优化，稳定省资源，但 off-policy 无法在线探索。
  • GRPO：PPO 改进，去掉 critic，用组内 N 个回答的相对优势（标准化）代替价值估计，省显存、可大规模。
RLHF 完整流程？reward hacking 是什么？
  • 流程：预训练 → SFT → 训 RM（人类排序数据）→ PPO/GRPO 用 RM 分数做奖励优化策略。
  • RM 作用：把人类偏好变成可微分标量，替代人在回路打分。
  • reward hacking：模型钻 RM 盲区刷分（堆长度、讨好词），分数虚高但质量没提升。缓解：KL 约束、更严奖励设计。
GRPO 优势怎么算？on-policy / off-policy？
  • 对同 prompt 采样 N 个回答，各得 reward r_i，组内标准化 A_i = (r_i - mean)/std，正负优势区分好坏。
  • 目标带 KL 惩罚项，约束策略不偏离参考模型。
  • on-policy：数据须由当前策略采样（PPO/GRPO），数据过期需重采、成本高；off-policy：可用历史数据（SFT/DPO）。
模型调优的步骤？
  • ① 明确目标与数据：定义任务、指标，收集/清洗/标注高质量数据（对齐分布、去脏）。
  • ② 基线与评估：先跑现有模型建基线，设计离线评测集（自动指标 + 人工/LLM 打分）。
  • ③ 选择方法：优先 prompt/上下文工程（零成本）→ 数据不够或需改行为再 SFT → 要按偏好优化用 DPO/GRPO/RLHF。
  • ④ 训练与调参：小规模实验定学习率/batch/epoch，用 LoRA 等省资源方案，监控 loss 与过拟合。
  • ⑤ 评估与迭代：对比基线看提升，检查失败 case，回补数据/调奖励，防止 reward hacking 与灾难性遗忘。
BERT 小模型相比大模型有哪些优缺点？
  • 优点：参数量小、推理快、成本低、易部署（可边缘/端侧）；对分类、命名实体、相似度、检索向量等固定任务够用；可针对垂直领域精调，可控性强、可解释性相对好。
  • 缺点：生成能力弱（主要做理解/编码，非自回归生成）；知识量少、泛化弱，复杂推理/多步/开放域对话不如大模型；需为每个任务单独微调，无法"一个模型打天下"。
  • 定位：小模型做特征提取/判别/召回（如 RAG 的 embedding、rerank、分类路由），大模型做生成与推理，二者常混合使用。

二、参数高效微调与分布式

LoRA 原理？rank 怎么选？
  • 假设权重更新低秩：ΔW = B·A，冻结 W 只训 A、B，推理合并 W+BA。
  • 可训练参数 <1%，省显存算力，不破坏原模型。
  • rank r 越大表达能力越强，通常 8/16/32，权衡效果与效率。
DeepSpeed ZeRO 三个阶段？
  • 显存三大块：参数、优化器状态、梯度。ZeRO 把它们切分到多卡。
  • ZeRO-1 切优化器状态；ZeRO-2 再切梯度；ZeRO-3 三者全切，每卡只留当前需要的参数片，按需通信取回，省显存最大，代价是通信开销。
FlashAttention 为什么快？bf16 vs fp16？
  • IO-aware：分块（tiling）+ SRAM 内 online softmax，避免 N×N 中间矩阵反复读写 HBM。
  • bf16 指数位同 fp32（8 位），动态范围大不易溢出，一般无需 loss scaling；fp16 范围小易溢出，需 loss scaling。

三、多模态与 CoT

CoT 是什么？隐式 vs 显式推理链？
  • CoT：让模型先输出中间推理步骤再给答案，提升复杂问题准确率。
  • 隐式 CoT：所有线索压进单条链，易退化依赖单一显著模态捷径。
  • 显式证据解耦：结构化拆成 <video><audio><reasoning><answer>，强制分模态提取再融合。
多模态模型（Omni）架构？为什么冻结编码器？
  • 视觉编码器（ViT）+ 音频编码器分别编码，经投影层对齐到 LLM 文本空间，LLM 做跨模态融合推理。
  • 编码器已预训练学好通用特征，冻结省显存，微调重点在融合推理而非重学特征。
自蒸馏、token 级对齐、JSD vs KL？
  • 自蒸馏：师生同基座，特权教师条件于答案、学生条件于输入，逐 token 对齐概率分布，实现零标注。
  • KL 不对称、P→0 处无穷、易长度爆炸；对称 JSD = ½KL(P||M)+½KL(Q||M)（M 混合分布）数值稳定、抑制漂移。
