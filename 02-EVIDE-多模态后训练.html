一、项目介绍（开场必背）

用一句话介绍这个项目

面向「视频+音频」多模态场景的人类意图理解，我提出并落地了一个叫 EVIDE 的两阶段后训练框架，核心是把大模型隐式的推理链改造成显式的视听证据分解，解决「标注成本高」和「模态信息损失」两大问题，在 HumanSense 基准上 30B 模型提升 6.9%、7B 模型提升 11.5% 并追平 30B。

用 2 分钟展开介绍（建议背熟）
  1. 背景与问题：Omni 模型（如 Qwen-Omni）做人类意图理解时有两个耦合瓶颈——① 标注成本高，传统方法依赖大规模人工标注的 CoT 数据做 SFT，贵且难扩展；② 模态信息损失，视觉和听觉线索被压进同一条隐式推理链，模型容易退化成只依赖单一显著模态的捷径（shortcut），比如"嘴上说好但表情犹豫"这种需要跨模态细粒度线索的场景就识别不准。
  2. 我的核心 idea：把隐式 CoT 重构成显式的四段式证据链 <video> <audio> <reasoning> <answer>，强迫模型先分别显式地提取视觉证据、听觉证据，再做跨模态融合推理。
  3. 阶段一 EDSD（证据分解自蒸馏）：为了不靠人工标注就能学出这个结构，我用特权教师-学生自蒸馏——同一个基座模型既当学生（只看输入）、又当特权教师（额外看参考答案），教师能"倒推"出更合理的证据，学生对齐教师的 token 级分布。但直接做会长度爆炸，所以我用了对称 Generalized-JSD 替换单向 KL，再加指数位置衰减聚焦早期证据 token。
  4. 阶段二 MIRL（模态重要性强化学习）：在 GRPO 基础上，用反事实消融（分别抹掉 video/audio 证据看答案怎么变）来估计每个模态的因果贡献，做符号相关的优势分配——答对了奖励起决定作用的模态，答错了惩罚主导错误的模态。
  5. 结果：EVIDE-30B 在 HumanSense 上较基线 +6.9%，7B +11.5% 且追平 30B，跨基准 IntentBench 也 +7.3%，增益集中在需要视听融合的任务上。论文 AAAI 2027 在投，一作。
你的个人贡献具体是什么？（区分"论文贡献"和"你做的部分"）
  • 方法层面：EDSD 的对称 GJSD 目标设计 + 指数 token 衰减；MIRL 的反事实消融 + 符号相关优势分配。
  • 工程层面：基于 Open-R1/TRL 二次开发多模态 GRPO 训练器，实现 token-local advantage 机制；DeepSpeed ZeRO-3 分布式训练、LoRA 微调、冻结视听编码器。
  • 评测层面：搭建统一多模态评测框架（多模型 adapter + VQA/AQA 评分）。
  • 提示 面试官常追问"这些是你独立做的吗？"，建议诚实回答"方法设计和核心模块实现是我主导，训练工程在 mentor 指导下完成"，避免过度夸大。

二、项目深挖问题（论文技术细节，重点背）

2.1 问题动机

什么是 CoT？隐式 CoT 和你的显式证据链有什么区别？
  • CoT（Chain-of-Thought）：让模型在给出最终答案前先输出一串中间推理步骤，提升复杂任务准确率。
  • 隐式 CoT：视频、音频等所有线索被压缩进一条没有结构区分的推理链，各模态信息混在一起。
  • 问题：压缩进单条链后，模型容易退化为依赖单一显著模态的捷径——比如只看嘴型或只靠语气下结论，忽略需要联合多模态的细粒度线索。
  • 你的做法（显式证据解耦）：拆成四段结构化格式，强迫模型先分别显式提取各模态证据，再做融合。论文 Figure 1 右下就是 EDSD 生成的样例轨迹。
你论文说的两个瓶颈"标注饥渴"和"模态信息损失"，为什么说它们是耦合的？
  • 这是论文的核心论证（abstract 和 intro 都强调了）：
  • 传统方法为什么需要海量手工 CoT 标注？恰恰是因为缺少一个显式的、模态结构化的推理接口——没有这个结构，就只能靠人工标注的 CoT 去"教会"模型怎么推理。
  • 反过来，因为推理链是隐式的、没有模态结构，奖励优化时视听线索被压缩，又导致模态信息损失。
  • 所以两个问题同源于"缺失显式模态结构接口"，EVIDE 用一个显式证据分解结构同时解决两个问题——这就是论文的核心卖点，面试时要能主动讲出来。

2.2 EDSD（证据分解自蒸馏）

什么是自蒸馏？你的教师和学生有什么不同？
  • 知识蒸馏：用教师模型的软标签/分布指导学生学习，学生拟合教师的输出概率分布。
  • 自蒸馏：教师和学生是同一个基座模型。区别在于条件输入：特权教师额外条件于参考答案 s_i（所以能"倒推"出更合理的证据），学生只条件于多模态输入 (x^v, x^a, q)。
  • token 级对齐：不是对齐整句，而是让学生每个 token 的预测分布逼近教师对应位置的分布（逐 token 算散度）。
  • 核心价值：教师被"喂"了答案，能生成高质量证据；学生模仿这些证据分布，零人工标注学会证据分解，解决标注成本高。
为什么朴素的自蒸馏会"长度爆炸"？
  • 单向的教师→学生 KL 与证据分解输出不匹配：教师条件于参考答案时，往往偏好又长又开放式的 <reasoning> 续写，鼓励学生不断延长这一段、延迟输出 EOS。
  • 后果：① 输出长度爆炸，更新变贵；② 晚期推理 token 主导了 loss，而真正决定答案的早期证据 token 反而监督不足。
  • 论文里给了具体数字：朴素 EDSD（单向 KL + 均匀权重）在长度预算内根本产出不了合法输出，长度直接冲到 1024+。
为什么用对称 Generalized-JSD 替代 KL？公式是什么？
  • KL 的问题：不对称；当教师分布某 token 概率趋近 0 时 KL 会发散、数值不稳定；单向 KL 让学生一味覆盖教师长尾，教师推理一"漂"学生跟着飘。
  • 对称 JSD：d = ½·KL(p_s ‖ m) + ½·KL(p_t ‖ m)，其中 m = ½·p_s + ½·p_t 是混合分布。对称意味着两个方向都约束；因为 m 是平均，p 或 q 为 0 处不会出现无穷大，数值稳定。
  • 关键思想：不是"把学生拉向教师特权分布"，而是"把两者对齐到共享的混合分布"——这样能抑制教师的长尾推理漂移，稳定 EOS 输出。
  • 效果：长度从 1024+ 降到 233。
为什么对早期 token 做指数位置衰减？
  • 证据链里早期证据 token 因果决定了后续推理和答案——证据错了，后面推理再对也没用；而晚期 <reasoning> token 容易"漂"。
  • 所以对 per-token 散度施加随相对位置指数衰减的权重：w = exp(-λ_p·(n-1)/T)，越靠前的证据 token 权重越大，越靠后的冗余 token 权重越小。
  • 效果：把监督聚焦早期关键证据，进一步抑制长度爆炸（长度再降到 220），并让证据提取更扎实。
  • 消融显示：加指数衰减后每个任务都涨，最明显的是 RG（+3.0 分）——因为长程意图链最需要早期 token 的强监督。
EDSD 的消融结论是什么？（三个层级）
  • ① 显式证据分解的增量价值：对比"只有 <reasoning>/<answer> 的隐式 CoT 自蒸馏"，EDSD 在多任务上提升，平均 +2.4 分，增益集中在模态敏感任务（GR +4.7、CM +3.5、PA +3.3 等）。
  • ② EDSD 整体优于隐式 CoT 基线：EDSD 单独就达到 0.707，超过 Qwen3-Omni-30B 基线（0.653）和 HumanSense-30B 专家（0.677），且无需任何手工 CoT 标注。
  • ③ 目标函数组件必要性：单向 KL 直接失效（长度爆炸）；加 GJSD 稳定格式；再加指数衰减进一步提升所有任务。

2.3 MIRL（模态重要性强化学习）

GRPO 原版在模态场景有什么不足？为什么需要 MIRL？
  • 标准 GRPO 给整条序列一个统一的优势信号，无法区分"答案对到底是谁的功劳"。
  • 多模态场景下，模型可能只靠单一显著模态（比如光听声音）就答对，导致跨模态线索被忽略——即"模态信息损失"。
  • MIRL 思想：按各模态对答案的真实因果贡献分配奖励，让"决定性模态"拿更多正反馈、"主导错误的模态"被更强惩罚。
什么是反事实模态消融？怎么量化模态的因果贡献？
  • 反事实（counterfactual）：问"如果某模态不存在，结果会怎样"。借鉴因果推断（Pearl）的思想。
  • 实现：把生成轨迹里的 <video> 或 <audio> 段内容替换成占位符（"No visual evidence." / "No audio evidence."），构造两条反事实轨迹 y^{-v} 和 y^{-a}。
  • 关键细节：保留周围的标签（tag），只替换内容——这样防止"格式损坏"被误判成"模态重要性"，让归因信号反映的是内容而非结构。这是论文强调的一个巧妙点。
  • 若抹掉某模态后答案大幅变差，说明该模态因果贡献大；几乎没变化则说明模型本来就没用上它。
符号相关优势分配（sign-dependent credit assignment）具体怎么算？
  • 对正优势（A_i > 0，答对）：用 answer-likelihood attribution。锚定 <answer> 段，计算在"抹掉某模态的前缀"下，ground-truth 答案 a* 的平均 log-likelihood s^{-v} / s^{-a}。谁被抹掉后答案似然下降更多，谁就更重要。用 sigmoid 把差异映射成模态权重：p^v = σ((s^{-a} - s^{-v})/τ)，权重 w = 2p。
  • 对负优势（A_i < 0，答错）：用 reasoning-support attribution。锚定 <reasoning> 段，计算在抹掉某模态的前缀下复现原错误推理的平均熵 h^{-v} / h^{-a}。谁被抹掉后复现错误推理的熵越高，说明它越"维系"着这个错误，就越该被惩罚。q^v = σ((h^{-v} - h^{-a})/τ)。
  • 为什么符号要分开：正负样本里"模态重要性"的语义不同——正样本问"谁支撑了正确答案"，负样本问"谁支撑了错误推理"。
  • 因子 2：w=2p 是为了保持平均更新尺度不变——当两模态同等重要（p=1/2）时，退化成标准 GRPO。
token-local advantage 是怎么做的？
  • GRPO 原本是序列级优势 A_i，每个 token 都一样。MIRL 把它换成token-local 优势：
  • <video> 段的 token 乘以 w^v·A_i，<audio> 段乘以 w^a·A_i，其余段（<reasoning>/<answer>）保持原始 A_i 不变。
  • 好处：只优化证据质量，不干扰答案本身的优化；最终答案的优化路径不受影响。
MIRL 的成本高吗？为什么？
  • 几乎零额外成本：不引入任何可训练参数，也不增加反向传播。
  • 只增加两次纯推理的前向（分别消融 video、audio 各一次）。
  • 论文给了精确分析：GRPO 成本 C_GRPO = Gα+β+γ，MIRL 成本 C_MIRL = Gα+β+3γ，相对开销 = 2γ/(Gα+β+γ)。在 G=8 下，额外成本仅 +6%~16%。
  • 这个"低成本高收益"是论文卖点之一，面试要主动讲。
MIRL 的消融结论？它的适用范围是什么？
  • MIRL vs GRPO（同 EDSD 初始化，仅替换奖励分配方式）：5 个模态敏感任务（TR/FR/RR/RG/ES）全部提升，平均 0.781→0.794，最大 RR +2.7、ES +1.3。
  • 适用范围（诚实说局限）：MIRL 的增益集中在双模态任务（视听都可能影响答案）。在单模态主导的任务上，MIRL 与 GRPO 持平——因为对比信号变弱。所以论文把它定位为"bimodal optimizer"，面试时主动说这个局限反而加分。

2.4 实验与结果

你的实验是怎么设计的？为什么用两个基座？
  • 主实验在 Qwen3-Omni-30B-A3B-Instruct 上做（对比其原始后训练配方 vs EVIDE 全流程）。
  • 迁移性验证：把 EVIDE 也应用到 Qwen2.5-Omni-7B-Instruct，验证设计不依赖特定骨干。因为 7B 模型开箱就不太遵守四段式输出格式，先花 3% 训练数据做了轻量格式稳定阶段（format-stabilization），教会它稳定遵循证据分解结构。
  • 跨基准：用 IntentBench 验证 HumanSense 上的增益不是过拟合特定评测。
结果里最有说服力的点是什么？
  • 7B 追平 30B：EVIDE-7B 达到 0.671，接近 HumanSense-30B（0.677），说明增益来自"显式保留并归因模态证据"，而非单纯堆骨干规模。
  • 增益集中在视听融合任务（AR/GR/PA/PC 等），正好命中"需要细粒度视听证据"的场景，佐证了方法动机。
  • 跨基准泛化：IntentBench 上 +7.3%，说明不是过拟合 HumanSense 统计特征，学到的证据分解结构可迁移。
为什么增益集中在视听融合类任务，这说明了什么？
  • 这些任务（AR 融洽识别、GR、PA、PC 等）需要保留细粒度的视觉+听觉证据再做跨模态推理，单靠一个模态会失败。
  • EVIDE 显式地、分别地保留了视听证据，MIRL 又正确归因了决定性模态，所以这类任务收益最大。
  • 这反过来印证了方法动机：不是"更大的模型"在起作用，而是"显式证据结构 + 模态感知奖励"在起作用。

三、八股基础（通用考点）

3.1 训练范式

SFT / RLHF / DPO / GRPO 分别是什么？有什么区别？
  • SFT（监督微调）：在 (prompt, 期望回答) 上做交叉熵训练，学会"照着答案说"。是后训练第一步，只模仿、不主动优化目标。
  • RLHF：先训 Reward Model 打分，再用 PPO 最大化奖励。流程 SFT → RM → PPO。问题：要训 critic、流程复杂、易 reward hacking。
  • DPO：跳过 RM 和 RL，直接从偏好数据用闭式 loss 优化，等价隐式拟合 RM。优点稳定省资源；缺点 off-policy，无法在线探索。
  • GRPO：PPO 改进，去掉 critic，对同一 prompt 采样 N 个回答，用组内相对优势（减组均值除以标准差）代替价值网络。省显存、稳定、可大规模。
RLHF 完整流程？RM 是干嘛的？什么是 reward hacking？
  • 流程：预训练 → SFT → 用人类排序数据训 RM（输入 prompt+回答，输出标量分数）→ 用 PPO/GRPO 以 RM 分数为奖励优化策略。
  • RM 作用：把人类偏好变成可微分的标量奖励，替代人在回路实时打分。
  • Reward hacking：模型钻 RM 空子（刷长度、堆讨好词），分数虚高但质量没提升。缓解：KL 约束、更严的奖励设计。
GRPO 为什么能去掉 critic？优势怎么算？
  • PPO 需要 critic（价值网络 V(s)）估计优势 A = R - V(s)，critic 要额外训练、占显存。
  • GRPO：同一 prompt 采样 N 个候选，每个打 reward r_i，做组内标准化 A_i = (r_i - mean(r)) / std(r)。
  • 用统计相对值代替绝对价值估计，省掉 critic。
  • 目标函数带 KL 惩罚，约束策略不偏离参考模型（通常是 SFT 后的模型）。
on-policy 和 off-policy 有什么区别？
  • on-policy：更新策略的数据必须由当前策略自己采样。PPO/GRPO 是 on-policy，每次更新前先 rollout，更新几次后数据"过期"要重采，计算量大、要分布式。
  • off-policy：可用历史或其他策略采样的数据更新当前策略，数据可复用。DPO、SFT 本质 off-policy。
  • 你论文"on-policy 自蒸馏"强调：学生用自己当前策略采样，再对齐教师分布，保持训练与推理分布一致，避免分布漂移。

3.2 参数高效微调与分布式

LoRA 的原理？为什么冻结主干只训 adapter？
  • 原理：假设权重更新低秩，ΔW ≈ B·A，A、B 是两个小矩阵（秩 r 远小于原始维度）。训练时冻结 W，只更新 A、B，推理合并成 W + BA。
  • 为什么冻结主干：可训练参数降到极小（通常 <1%），显存算力大幅下降，不改原结构、便于切换部署。
  • 你的场景：只解冻 LLM 文本主干的线性层（LoRA 注入处），冻结视听编码器——编码器已预训练、特征够好，多模态微调重点在"融合推理"而非"重学特征"。
  • rank 选择：r 越大表达能力越强但参数越多，通常 8/16/32。
DeepSpeed ZeRO 三个阶段？显存怎么省的？
  • 显存主要被参数、优化器状态（Adam momentum+variance）、梯度占据，ZeRO 把这三块切分到多卡。
  • ZeRO-1：只切分优化器状态。
  • ZeRO-2：再切分梯度。
  • ZeRO-3：三样全切分，每卡只保留当前计算需要的参数片，需要时通信取回，省显存最大。
  • 代价：通信开销增加，需高速互联（NVLink/InfiniBand）。你用 ZeRO-3 因为 30B + 多模态输入显存压力大。
FlashAttention 为什么快？bf16 和 fp16 的区别？
  • FlashAttention：传统 attention 把 QK^T 的 N×N 中间矩阵写到 HBM 再读回，IO 是瓶颈。FlashAttention 是 IO-aware 的——分块（tiling）、在 SRAM 里完成 softmax 分块重算，避免反复读写大矩阵。
  • 分块 softmax：softmax 分母需全局 max/sum，用 online 方式分块算再合并，数学正确且不落地大矩阵。
  • bf16 vs fp16：fp16 指数位少（5 位）范围小、易溢出；bf16 指数位和 fp32 一样 8 位，动态范围大、不易溢出，但尾数少精度略低。
  • 混合精度：fp16 需 loss scaling（放大 loss 防下溢），bf16 范围大通常不需要，更稳。

3.3 多模态

多模态模型（Qwen-Omni）的架构特点？视听编码器为什么冻结？
  • Omni 模型：同时处理文本+图像/视频+音频，用独立视觉编码器（ViT）和音频编码器把各模态编码成 token，经投影层对齐到 LLM 文本嵌入空间，交给 LLM 主干做跨模态融合推理。
  • 跨模态对齐：多模态输入映射成"LLM 能读懂的 token 序列"，语言模型充当通用推理引擎。
  • 为什么冻结编码器：编码器已预训练学会通用特征；冻结省显存算力，微调重点在"多模态融合与推理"（LLM 主干 + 投影），而非重学底层特征。
什么是知识蒸馏？soft label 和 hard label 的区别？
  • 知识蒸馏：用教师模型的输出分布指导学生学习，传递"暗知识"。
  • hard label：one-hot 真值，只告诉"答案是 A"，信息量少。
  • soft label：教师输出的概率分布，告诉"A 最可能、B 次可能"，携带类别间相似性的暗知识，学生能学到更平滑的决策边界。
  • 通常用温度 T 软化：softmax(z/T)，T 越大分布越平滑，蒸馏时学生也用相同 T，推理时 T=1。
什么是反事实（counterfactual）？它和相关性（correlation）有什么区别？
  • 相关性：观察到"有视频时答案对得多"，但可能是伪相关（有视频的数据本身更简单）。
  • 反事实/因果：问"如果抹掉视频，答案会怎样"，干预（intervention）后看结果差异，才能判断真正的因果贡献。
  • 你的 MIRL 就是借鉴因果推断（Pearl 的 do-算子思想），用消融（intervention）而非相关性来估计模态重要性。

3.4 评测与调优

大模型评测怎么做？为什么要有多个基准？
  • 用统一评测框架，对多个 benchmark（HumanSense、IntentBench）和多个模型做打分（VQA/AQA），保证可比性。
  • 多个基准是为了验证泛化：单一基准可能过拟合其统计特征，跨基准（IntentBench）才证明方法真正可迁移。
  • 你的项目里，自研评测框架用注册式 benchmark + 多模型 adapter，方便横向对比。
什么是长度爆炸（length explosion）？还有什么缓解手段？
  • 长度爆炸：RL/蒸馏训练中，模型发现"写更长"能刷高 reward（或拟合教师长尾），于是输出越来越长、不吐 EOS，训练变慢、质量下降。
  • 你的缓解：对称 GJSD（抑制长尾漂移）+ 指数位置衰减（弱化晚期 token 监督）。
  • 其他常见手段：长度惩罚（length penalty）、reward 里加长度项、token 级奖励裁剪、KL 约束。
